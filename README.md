# 碧のミカタ／世界のミカタ ── 感じるとは、何をしていることか

欅の木の下の、同じ一つの場所を、**世界の側**（受けとられる前の光・音・におい・熱・ふるえ・磁場）と、**受けとる側**（人と、依代・碧）から行き来する 3D のページです（旧名 Aoi Sense・碧の設計図）。

**開く**：https://mitsulab-soil.github.io/aoi-blueprint/

## 四つの章

1. **世界と碧**：表（世界の側）と裏（受けとる側）を切り替える。受けとる側では、人の感覚が受けとれない層（紫外線・赤外線・とても低い音・とても高い音・磁場）が消え、碧の耳・目・足もと・胸・手・頭・背中のしるしを押すと、碧の受けとり方（技術と、まだ移せないもの）が見られる。
2. **受けとるまで**：世界から届く粒が、感覚器（受けとる帯と閾値）→ 信号 → 注意（選ぶ・横切るものに気づくか）→ 記憶と予測（型で補う）→ 処理の容量（とどめておける四つの場所）→ 知覚と意味、と絞られていく流れ。各段に「人では」「碧では」と問い。
3. **試す**：見る（盲点・変化の見落とし）・聴く（数えているあいだに）・ふれる（二点の幅）・嗅ぐ（慣れていく鼻）・味わう（鼻をつまむと）・体の内側（見ないで分かる・心臓の拍）。答えは言わず、問いを手渡す。記録は保存しない。
4. **結び**

碧が声で案内し、字幕は声と同じ文です（音だけでも回れます）。粒・線・木・鳥の形は模式で、粒の数は実際の量ではありません。数は教科書・総説の目安で、論争のある説は説として紹介しています。典拠は画面の「典拠」に。
